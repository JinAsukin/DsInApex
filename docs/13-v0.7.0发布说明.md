# Ds in Apex v0.7.0 · 首个便携版

把**飞智八爪鱼 4（APEX 4）**在 PC 上虚拟成**原生 PS5 DualSense** 的 Windows 客户端 ——
换来自适应扳机（FORCEADAPT）与音频触觉转译。

界面为 **WinUI 3 原生应用**，完整简体中文，托盘常驻，**便携免安装**。

## 快速开始

1. 解压到**任意目录**（路径可含空格与中文）。
2. 双击 **`DsInApex.exe`**。
3. 左侧 **驱动管理** 页 → 点「安装/修复」→ 在 UAC 提示中确认 → **重启 Windows**。
   （usbip-win2 与 HidHide 都是内核驱动，重启是必须的。）
4. 把八爪鱼 4 切到 **DInput 模式**（飞智游戏厅 / Space Station 里改），用 USB 线或接收器连接。
5. 回到仪表盘，点「启动桥接」。手柄即以 **DualSense** 身份出现在系统中。

**升级**：下载新目录替换即可（用户数据在 `%LOCALAPPDATA%`，不受影响）。
**卸载**：删除目录即可；已安装的驱动请在 Windows「设置 → 应用」中自行卸载。

## 本版内容

**七个页面**：仪表盘 · 游戏库（**215 款**，含自适应扳机/触觉支持标记）· 学习记录 ·
驱动管理 · 硬件测试 · 诊断面板 · 设置

**后台能力**：托盘 **20 项**控制面 · 托盘气泡通知 · 开机自启（含**路径漂移自动纠偏**，
便携版搬家后自启不会变死链）· 关闭窗口行为可配 · 三条退出清理路径

报告，ZIP 导出）—— 上游 1127 行 PowerShell 脚本的 C# 原生重写

**本地化**：中英界面热切换（无需重启）

## 与上游的关系

本版是 [`ReynArts/ApexSenseBridge`](https://github.com/ReynArts/ApexSenseBridge) **v0.6.3**
的衍生作品：

- **C++ 引擎层保持上游原样**（基线 `e438507`），以便持续跟进上游修复
- **UI 层**由上游的 WPF 托盘界面**全量重写**为 WinUI 3 —— 因此界面**不与上游同步**
- 上游仅有英/法界面语言，中文是**全新翻译**
- 交付形态由 Inno 安装器改为**便携绿色包**

刻意保持兼容的部分：设置文件位置与字段名、会话互斥对象名、引擎命令行参数。
**本程序与官方版共用同一用户数据目录**，学习记录互通。

## 已知限制

- **音频触觉**的数据源是「游戏写给虚拟 DualSense 的输出报告」，**不是系统音频回环** ——
  在扬声器上放音乐不会让相关指标变化，必须在支持该特性的游戏里才有效。
- 界面中设备名显示为 `Flydigi VADER3` 是上游固件遗留字符串（`VID_04B4` 为 Cypress 通用 VID），
  型号判定走 `VID_04B4&PID_2412` 实例 ID，功能不受影响。
- 首次安装驱动后必须重启；未重启时桥接会启动失败。
- Windows 11 会把新托盘图标折叠进「隐藏图标」面板，需要手动拖出。
