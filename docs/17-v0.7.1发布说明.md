# Ds in Apex 0.7.1 发布说明

发布日期：2026-10-04
产物：`DsInApex-Portable-0.7.1.zip`（104.8 MB，解压 229.2 MB）

## 这是什么

把飞智八爪鱼 4（APEX 4）在 PC 上虚拟成**原生 PS5 DualSense**，从而在 PC 游戏里获得
**自适应扳机**与**音频触觉转译**。本仓库是 `ReynArts/ApexSenseBridge` 的衍生作品：
**C++ 引擎保持上游原样**，UI 层用 WinUI 3 全量重写并补齐简体中文。

## 本版变化（相对 v0.7.0）

- **上游引擎基线升级：`0.6.3 (e438507)` → `1.0.0-beta.9 (f17bca8)`**
  - 引擎定位、命令目录、输出解析、会话管理、硬件测试全部适配新基线
  - 界面同步新增命令与文案（硬件测试页、本地化字典）
- 修正 `version.json` 中引擎版本与实际打包引擎不一致的问题（脚本此前仍硬编码 `0.6.3`）

## 下载与快速开始

1. 下载 `DsInApex-Portable-0.7.1.zip`，解压到任意目录（**路径建议纯英文**）。
2. 运行 `DsInApex.exe`。首次使用请在「**驱动管理**」页安装前置驱动并**重启**。
3. **手柄必须处于 DInput 模式**（见下方已知限制）。
4. 启动桥接后，游戏里把控制器选为 DualSense 即可。

> 便携版不写注册表安装项、不注册系统服务。升级 = 换目录，卸载 = 删目录。
> 用户数据保留在 `%LOCALAPPDATA%\ApexSenseBridge\`，删程序不会带走。

## 已知限制

- 🔴 **手柄必须在 DInput 模式**。切到 XInput 模式后，手柄会**整体换 USB 身份**
  （`04B4:2412` → `045E:028E` 冒充微软 Xbox 360，驱动变 `xusb22`），
  **飞智私有接口全部消失**，程序将无法识别设备。这是硬件行为，不是软件缺陷。
- **Toast 通知不可用**（self-contained + unpackaged 下缺运行时资源 DLL），已改用托盘气泡。
- 非管理员运行时 WMI 进程启动追踪会「拒绝访问」，自动降级为 250 ms 轮询——属预期行为。
- `test-profile-switch` 仅 APEX 5 支持，APEX 4 上界面会自动隐藏该入口。
- **音频触觉的输入源是「游戏 → 虚拟 DualSense 的输出报告」**，不是系统音频回环；
  没有游戏在跑时相关指标恒为 0，放音乐不会有效果。
- 真实游戏实测尚未完成（需要手柄 + 支持 DualSense 的游戏）；自动化验收已全绿。
